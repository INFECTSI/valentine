Importer SeLoger ou Leboncoin

Pas besoin de copier du code. Tu glisses un bouton dans tes favoris, puis tu cliques dessus sur la page SeLoger ou Leboncoin.

Le plus simple : le favori magique

  1. Affiche la barre de favoris avec Ctrl + Maj + B.
  2. Glisse le bouton orange ci-dessous dans la barre de favoris.
  3. Ouvre SeLoger ou Leboncoin, fais ta recherche normalement.
  4. Clique sur le favori « Importer dans Valentine ».
  5. Une popup dit « X annonces importées ». Reviens ici et relance la recherche.

Chargement…

Après un import, ouvre Valentine et clique sur l’onglet « Importées » sous les résultats. Les annonces SeLoger et Leboncoin apparaissent aussi dans les sources.

Autre méthode : coller le code de la page (plus technique)

Important : la case « HTML » doit contenir le code source de la page, pas son adresse. Si tu colles un lien, ça ne marchera pas.

Pour obtenir le code : F12 → onglet Elements → clic droit sur <html> → Copy → Copy outerHTML. L’extension Valentine pour Chrome / Edge fait la même chose en un clic.
Télécharger l’extension Valentine (.zip) — dézippe le fichier, puis charge le dossier dans chrome://extensions.
