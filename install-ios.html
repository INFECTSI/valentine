Valentine sur iPhone

Pas besoin de l’App Store. Tu l’ajoutes à l’écran d’accueil : il s’ouvre en plein écran comme une application.

Scanne ce code avec l’iPhone Copier le lien

Installation en 4 étapes

  1. 1Ouvre le lien dans Safari (pas Chrome).
  2. 2Appuie sur le bouton Partager □↑ en bas de l’écran.
  3. 3Fais défiler et choisis « Sur l’écran d’accueil ».
  4. 4Appuie sur « Ajouter » en haut à droite.
L’icône Valentine apparaît sur ton écran d’accueil. Elle ouvre le site en plein écran, sans barre d’adresse.

Et sur Android ?

Ouvre le lien dans Chrome → menu ⋮ → « Installer l’application » ou « Ajouter à l’écran d’accueil ».

Une vraie application App Store ?

Oui, c’est possible avec Capacitor : le site est enveloppé dans une coquille iOS native. Il faut un Mac avec Xcode, un compte Apple Developer (99 €/an) et un serveur permanent pour l’API. Pour une app publique, il faut aussi ajouter des fonctions natives (notifications, favoris hors ligne, partage) pour passer la validation Apple.

Le guide de déploiement est dans DEPLOYMENT.md. La version PWA ci-dessus marche dès maintenant, sans compte Apple.
